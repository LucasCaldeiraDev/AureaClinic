## Navegação
- Header fixo enxuto: logotipo + 3 âncoras (Tratamentos, Experiência, Contato) + botão CTA.
- Comportamento: esconde ao rolar para baixo, reaparece ao rolar para cima.
- Mobile: logotipo + CTA; âncoras em menu simples (sem hamburger complexo — LP curta).
- Botão flutuante de WhatsApp aparece após a seção 3 (padrão do nicho, discreto).
